# 🇳🇬 SellJapaProperties (SellJapaProperties.ng)

> **Confidential Liquidation & Escrow Marketplace for Nigerian Relocators & Diaspora Investors**

SellJapaProperties is a purpose-built proptech platform enabling property owners relocating from any of Nigeria's 36 States + FCT Abuja to liquidate residential homes, lands, whole-house bundles (house + car + solar inverter + furnishings) quickly and privately with 100% verified legal escrows.

---

## 🌟 Key Features

### 1. 🛡️ Privacy & Security First
- **Automatic House Detail Masking**: Sensitive asset details (exact estate address, house numbers, 4K interior galleries, title deeds) are masked for unauthenticated visitors.
- **Flight & Personal Data Shielding**: Specific travel flight numbers and dates are never displayed or stored, protecting relocating families against security risks.

### 2. ✨ Whole-House Takeover Packages
- Liquidate complete estates in a single closing: property, vehicle (with customs duty papers), solar inverter system (with warranty), and home furnishings.

### 3. 💳 Fair Proptech Fee Architecture
- **₦5,000 Platform Service Token Fee**: Upfront token fee covering AI valuation, nationwide listing hosting, and marketing exposure across 25,000+ local & diaspora cash buyers.
- **On-Ground Scout Success Commission Model**: Certified field scouts on the ground across all 36 states work on a success commission (e.g. 2%) paid strictly from seller escrow proceeds upon successful closing.

### 4. 💼 Role-Isolated Portals
- **Seller Portal**: Manage confidential relocation listings, inspect incoming escrow offers, and monitor settlement payouts in the Escrow Payout Vault.
- **Buyer Portal**: Submit binding escrow bids with 10% trustee holds, track saved watchlist properties, book live 4K video inspection tours, and manage diaspora multi-currency wire inflows (USD, GBP, EUR, CAD).

### 5. ⚡ Automated Escrow Settlement to "SOLD"
- When seller confirms handover and releases escrow funds, net balance is settled to the seller's bank vault and the listing is automatically stamped as `🔴 SOLD VIA ESCROW` across the live marketplace.

### 6. 📹 4K WebRTC Live Video Inspection & Chat Room
- Encrypted peer-to-peer live video inspection and distinct deal rooms tailored for buyers and sellers.

## 🛠️ Technology Stack

- **Frontend**: React 19, Vite, Tailwind CSS
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, CSS Glassmorphism
- **API Simulation Layer**: Simulated REST & WebRTC API services with LocalStorage persistence

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/kizito-nwaodu/selljapaproperties.git

# Navigate into directory
cd selljapaproperties

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
